# Expense Calculator

## Overview
Expense Calculator is a Java-based application designed to help users track, manage, and analyze daily expenses efficiently. The project demonstrates the implementation of Object-Oriented Programming (OOP) concepts, clean modular design, and efficient data handling using Core Java.

---

## Features
- Add new expenses
- View all recorded expenses
- Categorize expenses
- Calculate total spending
- Track daily and monthly expenses
- User-friendly console interface
- Exception handling for invalid inputs

---

## Technologies Used
- Java
- OOP Principles
- Collections Framework
- Exception Handling
